# 🐤 Flappy Bird

🐤 Flappy Bird — a modern, dependency-free HTML5 game built with Canvas and vanilla JavaScript.

🎮 **Play Online:** https://gamelabz.github.io/html5-game-flappy-bird/

## 📸 Screenshot

![Flappy Bird](assets/images/screenshot.png)

## 🎯 About

Tap to flap, fight gravity, and thread the gaps between pipes in this endless side-scroller.

## 🕹️ Controls

- Flap: Space / Click / Tap
- Pause: P
- Restart: R

## ✨ Features

- Gravity + flap impulse physics
- Scrolling pipes with random gaps
- Animated sky, glowing bird and pipes

## 🚀 Run Locally

No installation required. Open the game directly in a browser:

```bash
# Option A: just open the file
open index.html

# Option B: serve it with a tiny static server
npx serve .
```

Then visit the printed URL (default `http://localhost:3000`).

## 🛠️ Tech Stack

- HTML5 `<canvas>`
- CSS3 (custom properties, flexbox, glassmorphism)
- Vanilla JavaScript (ES2020, no frameworks)
